# SEES-DTE (Monorepo)
Backend (Node.js + Express), Frontend (React + Vite) y App iOS (React Native/Expo enfocada en iOS).

## Estructura
- backend/  → API Express (lista para producción en Ubuntu, PM2, Nginx)
- frontend/ → React (Vite), responsive, español, paleta SEES
- mobile/ios-app → React Native (Expo), iOS-only (resumen DTEs)
- deploy/   → Nginx (HTTP/HTTPS), PM2 config
- docs/     → Guías PDF y pasos
